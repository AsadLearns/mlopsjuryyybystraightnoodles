7. Comprehensive Jury Viva Defense Q&A

Q1: Why is Pickle prohibited for production model serialization?
Answer: Pickle serializes Python bytecode instructions rather than raw weights. Calling pickle.load() executes arbitrary code inside __reduce__, creating a severe Remote Code Execution (RCE) vulnerability. In contrast, ONNX is a declarative Protocol Buffer specification that cannot execute arbitrary code.
Q2: Why is ONNX Runtime significantly faster than PyTorch on CPU?
Answer: ONNX Runtime applies graph optimizations: constant folding, dead code elimination, and operator fusion (combining operations into single kernel calls). It utilizes hardware-specific AVX2/AVX-512 SIMD vectorization and has zero Python interpreter overhead during inference.
Q3: How does the BranchPythonOperator prevent model regression in Airflow?
Answer: The BranchPythonOperator pulls the newly evaluated model's accuracy via Airflow XCom and compares it against the production baseline. If the new model fails to beat the threshold, it dynamically branches to skip_deployment, preventing degraded models from replacing working production artifacts.
Q4: What is the fundamental difference between Data Drift and Concept Drift?
Answer: Data Drift (covariate shift) refers to changes in the input feature distribution $P(X)$ without changes to the underlying target relationship $P(Y \mid X)$ (e.g., buyers viewing larger homes, but price per sqft remains unchanged). Concept Drift refers to changes in the mathematical relationship $P(Y \mid X)$ itself (e.g., identical homes doubling in price due to inflation or interest rates, making historical model weights inaccurate).
Q5: Why is the Kolmogorov-Smirnov test superior to comparing simple mean and standard deviation?
Answer: Comparing mean and standard deviation only captures first- and second-order moments and is blind to bimodal shifts, skewness, or tail anomalies. The Two-Sample KS-test compares empirical cumulative distribution functions non-parametrically across the entire distribution spectrum, making it distribution-free and highly sensitive to arbitrary shifts.
